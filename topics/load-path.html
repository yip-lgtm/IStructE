為何係考試核心

Section 1(a) 要求你畫兩套 distinct schemes，同時表達：

  • 竖向荷载點走（slab → beam → column → foundation）
  • 横向穩定點走（floor diaphragm → core / brace / frame → foundation）
  • Transfer 結構點改路（例如大跨下面有柱網變）

考官最常見的失分：只畫框架，唔畫箭頭；或者箭頭不合理（例如力徑直接跳去基礎，唔經過柱）。

考試必畫三樣野

  1. Overall framing plan — 柱網、大樑方向、core 位置
  2. Load path arrows — 竖向（紅）+横向（藍），每層都要有
  3. Critical detail — transfer beam、cantilever root、connection、或 foundation

例：大跨車間用 truss，下面有 office。你必須畫出 truss bottom chord 點把力交給下面柱，以及下面柱點去基礎。

Transfer Structures 常見場景

  • 大跨下面柱網不同（例如上層 15 m grid，下層 7.5 m）
  • Cantilever 或 hanging floor（例如 control tower、atrium edge）
  • 現有結構上加層（要檢查原有柱能否承受新荷载）

寫推薦時要講：為何選這個 transfer 方式（深度、施工難度、carbon）。

下一步練習

拿你 Jan 2026 Manufacturing Building 的兩套 scheme，每套加畫 3–4 條 load path 箭頭。再寫一句：「横向力從邊界點去 core。」
