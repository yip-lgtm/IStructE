SESSION 1 · INITIAL THOUGHTS
Design Appraisal + Assumptions + Two Distinct Viable Schemes + Foundation + Recommendation

SESSION 2 · CALCULATIONS + DRAWINGS

建立 form and size = 滿足 bending / shear / deflection / fire / robustness，唔係只計一個 moment。
SESSION 3 · METHOD STATEMENT
Construction sequence · Temporary stability · Crane / large member erection · Testing
